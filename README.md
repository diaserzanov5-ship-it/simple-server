# Простой HTTP-сервер

Минимальный сервер на Python без сторонних библиотек.

## Локальный запуск

В Windows открой PowerShell в этой папке и выполни:

```powershell
python server.py
```

Открой <http://localhost:8000>. Проверка состояния: <http://localhost:8000/health>. Остановка: `Ctrl+C`.

## Развёртывание

В репозитории есть `render.yaml` для Render. Подключи этот GitHub-репозиторий через **New → Blueprint** в Render. Конфигурация запускает Python-сервер и проверяет `/health`. Бесплатный сервис может засыпать после периода бездействия.
